# Improvement Reports

This folder holds all improvement reports produced during meta-analysis cycles for the LLM Journey project.

See `$LLM_JOURNEY_IMPROVEMENT_PROTOCOL` for the full protocol that governs how these reports are created, structured, and used.

---

## What Goes Here

| Report Type | Naming Convention | Produced By |
|---|---|---|
| Per-agent findings | `META-YYYYMMDD-<CR-ID>-<role>-findings.md` | Each agent during backward pass |

---

## Templates

Report templates are defined in `$LLM_JOURNEY_IMPROVEMENT_PROTOCOL` and as standalone files:

- Per-agent findings: `$GENERAL_IMPROVEMENT_TEMPLATE_FINDINGS`

---

## Conventions

- Report files are **not** edited after creation. They are historical artifacts once produced.
- Do not add non-report files to this folder. Protocol lives in `$LLM_JOURNEY_IMPROVEMENT_PROTOCOL`.
